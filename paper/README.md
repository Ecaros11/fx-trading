# 模拟盘工具集

> **先读这一页的最后一部分"能力边界"。这份工具的价值不在预测，在执行测量。**

---

## 三个工具

| 工具 | 什么时候用 | 干什么 |
|---|---|---|
| `direction_score.py` | 每天一次 | 给出 −10~+10 的方向分 + 1 天收益预测 + 持仓建议 |
| `trade_gate.py` | **每次下单前** | 五道是非题闸门 + 仓位计算 |
| `trade_report.py` | 平仓后 / 累计 20 笔后 | 真实成本（bp）+ 违规统计 |

---

## 日常流程

### 第一步：看方向分

```bash
python direction_score.py --refresh --refresh-funding
```

输出示例：

```
  可用分量   5 / 5

  分量                          原值       标准化     方向
  趋势 距MA120              +0.0495     +0.90     看多
  波动率30                  +0.0059     -0.88     看多
  跨截面排名                  +0.3846     -0.39     看空
  跨截面离散                  +0.0008     +1.79     看多
  过去1天                   +0.0202     +0.90     看空

  映射到 −10~+10          +6.5
  [#########################################.........]
   -10                    0                    +10

  持仓建议
    无建议（分数不参与持仓决策）
```

**⚠️ 一定要看「可用分量」那一行。少于 5/5 说明有数据缺失，得分是残缺的。**
有缺失就加 `--refresh-funding` 补齐。可用分量 < 3 时工具会拒绝出分。

**建议的读法：**

| 得分分位 | 建议 |
|---|---|
| 任何分位 | **无建议** —— 分数不参与持仓决策 |

**为什么连「低分空仓」也不给：**

```
同一份模型的 walk-forward 样本外分档（40 窗口）：
  Q1（得分最低）  4680 样本  +0.1774%   ← 最好
  Q5（得分最高）  4680 样本  −0.0256%   ← 最差
  corr(得分, 收益) = −0.0154

⇒ 得分最高的那一档收益最差。按样本内方向写建议会得到相反的结论。

即使是历史最低的 20%，样本外后续 1 天平均仍是 +0.18%（正的）。
「空仓」是在放弃唯一被验证过的正期望来源（beta），还要再付一次平仓成本。
```

**这份 README 的早期版本在这里写的是「≤20% → 空仓」。那是错的（基准选错的老毛病换了个形式），已删除。**

### 第二步：下单前过闸门

```bash
python trade_gate.py
```

它会：
1. 问你的交易计划（入场/止损/止盈/本金/风险比例）
2. **按规则算仓位**（不是你想下多少）
3. 问五道是非题，任何"否"就拒绝
4. 把结果写进 `journal.csv`

**五道题：**

```
① 信号：你的规则给出了明确的开仓信号吗？
② 止损：止损在噪声之外吗？（≥3.5%，日波动约 2.3%）
③ 仓位：实际风险你能接受吗？
④ 事件：未来 4 小时没有非农/FOMC/CPI 吗？
⑤ 心理：你不是在"想回本"或"怕错过"吗？
```

**它还会检查最小下单量的问题：**

```
⚠️  最小下单量强迫你放大 3.82 倍
    实际单笔风险 3.03 USDT = 本金的 19.1%
    而规则上限是 5.0%
    ⇒ 这个账户规模执行不了你的规则
```

### 第三步：平仓后补数据

```bash
python trade_report.py --close
```

需要填：实际入场价、实际平仓价、整笔手续费（从币安"资金流水"查）。

### 第四步：累计 20 笔后出报告

```bash
python trade_report.py
```

报告回答两个问题：

```
① 真实单边成本是多少 bp？
   入场滑点 + 手续费 = ?
   我们研究用的假设是单边 5bp
   
② 违规统计
   守规矩 / 有违规 各多少笔
   违规类型分布
   守规矩 vs 有违规 的结果对比
```

---

## `journal.csv` 字段说明

| 字段 | 填的时机 | 说明 |
|---|---|---|
| `id` ~ `gate_result` | 跑 `trade_gate.py` 时自动填 | 计划部分 |
| `fill_entry` `fill_exit` `fee_total` | 跑 `--close` 时填 | 成交部分 |
| `stop_moved` | 跑 `--close` 时填 | 持有中改过止损吗 |
| `exit_per_plan` | 跑 `--close` 时填 | 按原计划平的吗 |
| `gate_result` 手改成 `OVERRIDE` | **闸门拒绝但你还是开了仓时** | 最严重的一类违规 |

## 能力边界（必读）

### `direction_score.py` 的实测样本外表现

```
1 天收益的 R² ≈ 0.0018        （解释 0.18% 的波动）

单周期 walk-forward（40 窗口）
  毛边中位  +0.035%
  毛边均值  −0.134%
  为正比例  50.0%

跨截面 walk-forward（40 窗口）
  按窗口聚类的 corr 均值  +0.006
  t = +0.48               （不显著）

毛边量级      0.7 ~ 3.1bp（单周期）/ 17 ~ 64bp（跨截面）
实测单边成本  5 ~ 12bp
```

**⇒ 成本大于信号。扣完成本后没有超过 beta 的方向性 alpha。**

### ⚠️ 一处已知不一致（必须知道）

```
本工具的 5 个分量组合【从未被样本外验证过】。

xsec_walkforward.py 验证过的： 排名 / 离散 / 市场均值 / 距MA120 / 波动率30
direction_score.py 实际用的：  距MA120 / 波动率30 / 排名 / 离散 / 过去1天
                              ↑ 去掉 市场均值（它切分符号不一致）
                              ↑ 加入 过去1天（单独通过，但这个组合没验过）

⇒ 上面的分档数字严格来说不能直接套用到这个组合上。
```

### 所以

| ✅ 正确用法 | ❌ 错误用法 |
|---|---|
| 当过滤器 —— 大部分时候告诉你不该动 | 当入场信号 |
| 当纪律锚 —— 把"今天该不该做"变成是非题 | 用它做空 |
| 用来记录你的执行数据 | 相信那个 ±6.5 的数字 |

### 为什么不做空

四轮样本外检验里，**没有找到任何一个可用的做空信号**：

```
跨截面模型的空方单笔净收益    −0.24% / −0.31% / −0.16%
所有做空条件的超额收益         都是负的
分档检验里得分最低的一档       后续 1 天平均仍是 +0.18%
```

**负分只用于"空仓"，不用于"反手做空"。**

## 模拟盘的两个目标

跑满 20 笔之后，只回答这两个问题：

```
① 你的真实单边成本是多少 bp？
   假设是 5bp，实测是多少？差多少？

② 你的违规率是多少？
   20 笔里违规 ≤ 3 笔（85% 守规矩）→ 可以继续
   违规 > 3 笔 → 问题在执行，不在方法，继续练
```

**不要用它验证方向。那条路四次都堵死了。**

**这三个工具真正测的是你，不是市场。**
